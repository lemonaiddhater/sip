# sip
# SIP Framework

A lightweight Python toolkit for network diagnostics and protocol analysis.

> Built for learning, testing, and analyzing network behavior in authorized environments.

---

## Features

-  VoIP analysis
-  DNS analysis
-  ARP analysis
-  Fast CLI interface
-  Fast/Powerful DoS interface 
-  Rich terminal UI
-  Cross-platform support

---

# Installation

## Windows (PowerShell)

```powershell
git clone 
cd sip
pip install -r requirements.txt
python sip.py
```
